# Movieverse

Movieverse is a Flask-based web application designed to provide personalized movie recommendations to users. It uses a clean and responsive UI to ensure an engaging experience for movie enthusiasts. The project is hosted at [flask-movieverse.vercel.app](https://flask-movieverse.vercel.app).

## Features

- **Personalized Movie Recommendations**: Offers curated movie suggestions based on user preferences.
- **Search Functionality**: Allows users to search for movies by title, genre, or other attributes.
- **User Authentication**: login and registration functionality.
- **Watchlist Management**: Uses a FIFO (First-In-First-Out) structure to manage the watchlist, ensuring the first added movie is the first to be watched.
- **Responsive UI**: Optimized for both desktop and mobile devices.



## Key Technologies

- **Backend**: Flask (Python)
- **Database**: SQLite (default) 
- **Frontend**: HTML, Tailwind CSS, JavaScript (with responsive design)
- **Hosting**: Vercel
